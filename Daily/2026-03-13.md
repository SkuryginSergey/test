**Управление кастомными кнопками**

Система должна:

- предоставлять возможность добавления новой кастомной кнопки, когда фокус установлен на шаге или диалоге (добавление кнопки при фокусе на другой кнопке не допускается);
- добавлять для кастомной кнопки параметр «Отображать в диалоге», значение которого задаётся исключительно через выражение;
- предоставлять возможность удаления кастомной кнопки;
- предоставлять возможность изменения названия кастомной кнопки;
- позволять назначать действия на кастомную кнопку по аналогии со стандартными кнопками («Далее», «Готово»);
- позволять изменять порядок кнопок и переносить их между шагами, соблюдая ограничения:

- кастомная кнопка всегда располагается между кнопками «Назад/Отмена» и «Далее/Готово»;
- кнопки «Далее» и «Готово» являются фиксированными и не подлежат переносу.

**Поведение шагов и диалогов**

Система должна:

- при создании диалога с единственным шагом отображать в дереве на вкладке «Диалог» только узел «Диалог» с параметрами: «Заголовок», «Инструкция» (инструкция переносится из параметров шага); вкладка «Действия» при этом остаётся без изменений;
- при создании первого шага формировать структуру вкладки «Диалог» следующим образом:

- **Диалог**. Параметры:

- Заголовок;

- **Шаг** (перенесённый из диалога). Параметры:

- Отображаемое имя;
- Отображать заголовок;
- Инструкция (перенесена из диалога);

- **Шаг** (созданный). Параметры:

- Отображаемое имя;
- Отображать заголовок;
- Инструкция;

- при создании первого шага формировать структуру вкладки «Действия» следующим образом:

- **Шаг** → «Далее»;
- **Шаг** → «Готово» (перенесено из диалога);

- при добавлении нового шага автоматически создавать новый узел «Шаг» в дереве на панелях «Диалог» и «Действия»;
- обеспечивать, чтобы при добавлении или переносе шагов последним в последовательности всегда оставался шаг с кнопкой «Готово»;
- при удалении шагов:

- позволять удалять любой шаг, при этом все действия и элементы управления, содержащиеся в шаге, удаляются автоматически;
- блокировать удаление шага, содержащего кнопку «Готово»: при попытке удаления отображать уведомление (toast/диалог) с указанием причины («Нельзя удалить последний шаг») либо скрывать кнопку удаления для такого шага;
- если после удаления шагов в диалоге остаётся только один шаг, автоматически сворачивать его обратно в узел «Диалог» в дереве структуры.
