# Вариант 1 для разработчиков

Профессиональный уровень/технические навыки по шкале 1-5?

На сколько технически сложные задачи может решать сотрудник. Его технический кругозор. Насколько важные задачи можно поручать сотруднику. Вносит ли он какой-то особый вклад в развитие продукта.
 ==
Продуктивность\результативность работы по шкале 1-5?

Количество полезной работы, выполняемой сотрудником, скорость ее выполнения, часто ли приходится возвращать результат на доработку или делается сразу хорошо, правильно и без лишних вопросов.
 ==
Коммуникативность по шкале 1-5?

На сколько легко с сотрудником коммуницировать по работе. Быстро ли находите совместное решение или чаще проводите время в бесполезных спорах.
